# Planificador de Viajes

Proyecto realizado para practicar conceptos de JavaScript y ECMAScript 6+.

## Funcionalidades

- Registrar destinos.
- Seleccionar fecha de viaje.
- Seleccionar transporte.
- Seleccionar alojamiento.
- Indicar número de personas.
- Calcular el costo del viaje.
- Aplicar descuentos por número de personas.
- Mostrar el itinerario.
- Calcular el costo total de todos los viajes.

## Conceptos de ECMAScript utilizados

- `const`
- `let`
- Funciones de flecha
- Template literals
- Destructuración implícita mediante parámetros
- `forEach()`
- `reduce()`

- Módulos ES6
